整体架构

前后端分离的单体应用，REST API 通信

浏览器 — Vue 3 + Vite + Tailwind CSS
← REST API (JSON) →
后端服务 — Spring Boot 3 + JDK 17
← JPA/Hibernate →
数据库 — PostgreSQL（本地或容器）

路由结构（前端）

Vue Router 路由表
/ 首页 — 工具导航卡片
/markdown Markdown 编辑器
/json JSON 格式化器

数据库实体

markdown_documents id, title, content, created_at, updated_at
json_records id, name, content, created_at, updated_at
operation_logs id, tool_type, action, detail, created_at

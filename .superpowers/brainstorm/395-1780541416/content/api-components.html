API 设计 & 组件树

REST API 端点

Markdown 相关
GET /api/markdown
获取文档列表
POST /api/markdown
创建新文档
GET /api/markdown/{id}
获取单个文档
PUT /api/markdown/{id}
更新文档
DELETE /api/markdown/{id}
删除文档
JSON 相关
GET /api/json
获取记录列表
POST /api/json
创建新记录
GET /api/json/{id}
获取单个记录
PUT /api/json/{id}
更新记录
DELETE /api/json/{id}
删除记录
操作日志
GET /api/logs
分页查询操作日志

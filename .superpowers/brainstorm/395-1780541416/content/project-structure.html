技术栈一览

前端框架 Vue 3 + TypeScript + Vite
CSS Tailwind CSS
状态管理 Pinia
Markdown 渲染 marked + highlight.js
JSON 处理 原生 JSON API
后端框架 Spring Boot 3 + JDK 17
持久层 Spring Data JPA
数据库 MySQL 8
